Curated List of SaaS Products & Open-Source GitHub Projects
Focused on Enterprise Architecture, Architecture Management, Application Portfolio Management, Capability Mapping & Technology Portfolio Management
Last updated: September 2026

This repository tracks notable Enterprise Architecture (EA) platforms and open-source projects for modeling, governing, analyzing, and planning the architecture of organizations across business, application, data, technology, capability, and strategic domains.

Examples include LeanIX, Ardoq, Bizzdesign, MEGA HOPEX, Orbus Software, Sparx Systems Enterprise Architect, Avolution ABACUS, Software AG Alfabet, Enterprise Studio, ValueBlue, Essential, Archi, OpenEA, Archie, ArchiPulse, and OpenArchi.

Open-source emphasis: The Open-Source section prioritizes projects that can serve as complete or partial alternatives to commercial EA suites, particularly tools supporting ArchiMate, TOGAF, architecture repositories, application portfolios, capability maps, architecture governance, dependency analysis, and technology landscapes.

Contributions welcome! Please add missing platforms, open-source projects, modeling tools, standards implementations, and supporting architecture-management technologies.

Open-Source GitHub Projects

Archi
One of the most established open-source Enterprise Architecture tools. Archi is a cross-platform ArchiMate modeling application for creating, analyzing, and visualizing enterprise architecture models. It supports the ArchiMate language and is designed for architects and modelers.

Essential Open Source
Open-source enterprise architecture platform centered around a governed enterprise ontology and repository covering business capabilities, processes, applications, information, technology, strategy, and dependencies. It provides architecture analysis, visualization, reporting, and portfolio-management capabilities.

OpenEA
Open-source enterprise architecture platform designed as a self-hosted, repository-first alternative to commercial EA suites such as LeanIX and Alfabet. It focuses on maintaining architecture knowledge as structured data rather than treating diagrams as the primary source of truth.

Archie
Open-source web-based enterprise architecture platform supporting TOGAF 9.2, ArchiMate 3.2, application portfolio management, capability mapping, architecture governance, Architecture Review Board workflows, and AI-assisted architecture.

Atlas Community Edition
Open-source, self-hostable enterprise architecture platform for cataloging applications, systems, servers, infrastructure, and data relationships. It provides an architecture landscape browser and API-oriented architecture repository.

ArchiPulse
Open-source web platform for storing, visualizing, navigating, and analyzing ArchiMate-based enterprise architecture models. It uses PostgreSQL and supports the ArchiMate Open Exchange Format.

OpenArchi
Open-source enterprise architecture management project built around an Architecture Model as a Service approach, with an architecture knowledge base, API-driven model management, graphical modeling, and TOGAF/C4-oriented concepts.

Additional Strong Open-Source Options

Modelio
Open-source modeling environment supporting UML, BPMN, requirements, and other architectural modeling disciplines. It can serve as a general-purpose modeling foundation around an EA practice.

Eclipse Capella
Open-source model-based systems engineering and architecture tool based on Arcadia. It is particularly useful for complex systems, capability decomposition, logical architecture, physical architecture, and engineering-oriented architecture work.

Eclipse Sirius
Open-source framework for creating custom graphical modeling workbenches and domain-specific architecture tools. Useful for organizations wanting to build their own EA modeling environment.

Eclipse Papyrus
Open-source UML/SysML modeling environment that can be used as a foundation for architecture modeling and custom enterprise-modeling workflows.

Structurizr
Open-source ecosystem based on the C4 model for describing software architecture as structured models and generating architecture diagrams and documentation from those models.

Structurizr DSL
Text-based architecture modeling language for defining software architecture models, relationships, views, and documentation as code.

PlantUML
Open-source diagramming tool supporting architecture and system diagrams from text definitions, useful for architecture-as-code workflows.

Mermaid
Open-source diagramming and visualization framework supporting flowcharts, architecture diagrams, dependency graphs, timelines, and other documentation-oriented architecture views.

Graphviz
Open-source graph visualization system useful for generating dependency maps, relationship diagrams, application landscapes, and architecture graphs.

Backstage
Open-source developer portal framework from the CNCF ecosystem that can provide an application/service catalog, ownership information, system relationships, and technical metadata useful as an operational complement to enterprise architecture.

C4-PlantUML
PlantUML extension implementing C4 architecture diagramming concepts for software and system architecture documentation.

C4-Builder
Open-source tooling for creating C4 architecture diagrams programmatically and integrating architecture descriptions into engineering workflows.

Archimate-PlantUML
PlantUML library for generating ArchiMate diagrams from text-based definitions, useful for architecture-as-code and version-controlled architecture documentation.

Archimate-Drawio
ArchiMate-compatible modeling workflows can be combined with open diagramming tooling to create lightweight architecture repositories and visualization pipelines.

OpenTelemetry
Open-source observability framework that can provide runtime telemetry and dependency information to complement an enterprise architecture repository with operational evidence.

OpenMetadata
Open-source metadata-management and data-catalog platform that can complement enterprise architecture by providing data assets, ownership, lineage, schemas, and governance information.

DataHub
Open-source metadata platform useful for connecting enterprise architecture with application, data, ownership, lineage, and technical-metadata inventories.

Apache Atlas
Open-source metadata and governance platform providing a foundation for managing relationships and lineage across enterprise data assets.

CMDBuild
Open-source configurable CMDB platform that can provide configuration-item inventories, relationships, dependencies, and operational data useful for feeding an enterprise architecture repository.

GLPI
Open-source IT asset and service-management platform with inventory and relationship capabilities that can complement application and technology portfolio management.

iTop
Open-source IT service-management and CMDB platform that can provide infrastructure, application, service, and dependency information for an EA repository.

NetBox
Open-source infrastructure resource-modeling platform useful for maintaining authoritative information about networks, devices, IP addresses, services, and infrastructure relationships.

Ralph
Open-source asset-management and data-center management platform that can contribute infrastructure and technology inventory information to enterprise architecture.

Apache Archiva
Open-source artifact repository that can complement architecture governance by providing controlled storage and lifecycle management for architecture artifacts and model outputs.

Open Policy Agent
Open-source policy engine useful for implementing architecture governance rules, compliance policies, technology standards, and automated architecture checks.

OpenRewrite
Open-source automated source-transformation framework useful for enforcing technology standards and executing large-scale application modernization initiatives identified through architecture rationalization.

Renovate
Open-source dependency-management platform useful for tracking and governing software technology lifecycles at application and portfolio level.

Apache Superset
Open-source analytics and dashboard platform useful for building custom EA dashboards over architecture repositories and portfolio datasets.

Metabase
Open-source business-intelligence platform that can be used to create custom reports and dashboards over enterprise architecture data.

Framework for building a self-hosted Enterprise Architecture platform: Combine OpenEA / Essential / Archie / ArchiPulse / Atlas as the architecture-repository layer, Archi for ArchiMate modeling, Structurizr / PlantUML / Mermaid / Graphviz for architecture-as-code and visualization, OpenMetadata / DataHub / Apache Atlas for data architecture and metadata, CMDBuild / iTop / GLPI / NetBox for operational application and technology inventories, and PostgreSQL / Neo4j as repository and relationship-storage options. Add Open Policy Agent for architecture governance and Apache Superset / Metabase for portfolio analytics. This combination can provide many of the core capabilities of commercial EA suites while keeping architecture data self-hosted and extensible.

Disclaimer

This is a curated ecosystem rather than a ranking or endorsement.

SaaS platforms differ significantly in architecture frameworks, metamodels, repository capabilities, integrations, governance, application portfolio management, pricing, and deployment models.

Some projects in the Open-Source section are complete enterprise architecture platforms, while others are Archimate/UML modeling tools, architecture-as-code projects, CMDBs, metadata platforms, visualization tools, or infrastructure-management systems that can complement or form part of an EA solution.

Open-source availability, licensing, features, and project activity can change over time.

Always verify licensing, security, maintenance status, architecture-framework support, scalability, and deployment requirements before adopting a project.
